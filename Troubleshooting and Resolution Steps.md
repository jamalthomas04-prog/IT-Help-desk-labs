# Desktop Replacement and Computer Deployment Lab

## Description
In this Service Desk Simulator lab, I worked through a customer support incident involving a desktop that would not power on. The outage prevented the employee from answering calls. The resolution involved checking the power connections, preparing a replacement desktop, and arranging shipment and return of the failed computer.

## Steps
1. Confirm the power failure by having the employee try a working outlet and a different power cable. If there are still no lights or fan activity, proceed with replacement.
2. Confirm whether the employee uses a laptop or desktop so the replacement matches their needs.
3. Open **Tools → Computer Deployment** and build a replacement desktop using **Server Imaging**, as required for Customer Support.
4. Obtain the site's receiving dock address through **Company Chat**.
5. Open **Tools → Ship Manager**, select the employee as the recipient, and enter the receiving dock address.
6. Select the prepared desktop and check **Include return label**.
7. Select **Rush Priority (Instant)** shipping and ship the replacement.
8. Instruct the employee to return the failed desktop using the prepaid return label after the replacement arrives.

## Result
The simulator marked the incident as resolved after the desktop replacement workflow.
